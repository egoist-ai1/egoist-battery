# Участие в разработке

Сообщения об ошибках и изменения кода приветствуются. Перед созданием публичного issue удалите серийные номера, MAC-адреса и личные пути. Локальные диагностические журналы не отправляются автоматически.

## Сообщение об ошибке

Укажите:

- модель устройства и способ подключения (USB, Bluetooth, BLE или радиоприёмник);
- версию и сборку Windows;
- программу, в которой заметна проблема;
- ожидаемое и фактическое поведение.

Приложите только очищенные от личных данных журналы и снимки. Не публикуйте содержимое личных отчётов целиком.

## Сборка и проверки

Используйте .NET SDK 8.0.425 из `global.json` и закреплённый runtime 8.0.31. Зависимости NuGet восстанавливайте в locked-mode.

```powershell
dotnet run --project tests/EgoistBattery.Tests -c Release
pwsh -NoProfile -File ./build.ps1
```

Сценарий сборки запускает 87 проверок, формирует одиночный EXE, установщик и portable-архив. Для сборки EXE и архива без установщика укажите `-SkipInstaller`. Сборка установщика требует NSIS 3.13; при отсутствии сценарий загружает переносимый набор инструментов с закреплённой SHA256-суммой из `packaging/toolchain.json`.

Перед отправкой PR выполните 87 проверок и полную сборку. Проверьте UI self-test командой `EgoistBattery.exe --ui-test --data-dir <временная-папка>`; состояния, которых нет на столе (зарядка, низкий уровень, ошибка, интервал, категория), воспроизводятся флагом `--fixture tests/fixtures/ui-devices.json`. Панель трея проверяет `EgoistBattery.exe --tray-hover-test --data-dir <временная-папка>`: на несколько секунд в трее появляются временные значки, мышь не двигается. Визуально проверьте окно при масштабе Windows 100%, 125%, 150% и 200% на экране Full HD.

## Точность и границы источников

Провайдеры читают доступные данные DualSense и DualShock 4 через USB/Bluetooth HID, Logitech через HID++ 2 GET1004/1000, Windows PnP HFP battery cache, уже подключённые BLE-устройства с Battery Service 180F и характеристикой 2A19, XInput и батарею компьютера. BLE-обнаружение не подключает устройства. Для Sony не отправляются HID output/feature reports. Для Logitech отправляются только документированные HID++ GET-запросы; SET-команды отсутствуют.

DualSense передаёт категорию заряда ступенями по 10%: показывайте весь интервал, не подменяя его точным процентом. Сохраняйте источник и время кэшированных данных Windows, если они известны. Не обещайте поддержку любой модели или точность, которой источник не предоставляет.

При изменении парсера или объединения результатов сохраняйте проверки парсера и merger; при изменении выбора видимых устройств — проверки visibility. Локальные журналы и отчёты могут содержать данные конкретной машины: удалите серийные номера, MAC-адреса, PIDs и персональные пути перед публикацией.
