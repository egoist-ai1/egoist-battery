# История изменений

## [Не выпущено]

Переработан интерфейс.

- Окно: журнал устройств по срочности вместо одинаковых карточек; устройства без данных о заряде собраны в тихий раздел; шкала-линейка с интервалом для DualSense и четырьмя ступенями для категорий Logitech; цвет только по состоянию.
- Движение: появление строк, заполнение шкалы, набегание чисел, пружина на нажатии и переключателях; отключается вместе с эффектами анимации Windows и в режиме высокой контрастности.
- Список обновляется на месте: раскрытые подробности и прокрутка больше не сбрасываются при каждом чтении.
- Значок в трее: капсула с заливкой по уровню и цветом состояния; отдельная палитра для светлой панели задач.
- Панель по наведению на значок: все подключённые устройства вместо серой системной подсказки.
- Самопроверка: `--ui-test --fixture <json>` (состояния, которых нет на столе), кадры движения, `--tray-hover-test` (панель на настоящих значках без движения мыши).
- В программу встроен шрифт Unbounded (SIL OFL).

## [1.0.0] - 2026-10-08

Первый публичный выпуск.

- Значок в системном трее для каждого подключённого устройства.
- Русское WPF-окно, работающее в отдельном процессе.
- Источники заряда для контроллеров PlayStation, устройств Logitech, Windows, Bluetooth LE, XInput и компьютера.
- Установщик NSIS для текущего пользователя и переносная сборка.
- SHA256-суммы артефактов и проверки сборки в CI.
