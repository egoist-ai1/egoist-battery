# Egoist Battery

Windows 10 (build 19041 и новее) / Windows 11, x64.

Запустите установщик Setup для обычной установки текущему пользователю.
Права администратора и отдельный .NET не нужны. Автозапуск и ярлык
можно выбрать в мастере. Удаление доступно в списке приложений Windows.

В архиве Portable находится самостоятельный EgoistBattery.exe.
Параметр --tray запускает только фоновый монитор.

Данные и настройки: %LOCALAPPDATA%\EgoistBattery.
При удалении программы настройки сохраняются.

https://github.com/egoist-ai1/egoist-battery
https://github.com/egoist-ai1/egoist-battery/releases/latest

Установщик не меняет драйверы, аудиоустройства и настройки других программ.
Бинарные файлы не подписаны. Обновление — установкой нового релиза.
