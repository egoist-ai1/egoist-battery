# Дизайн

## Направление

Графитовая палитра без декора. Цвет несёт только заряд: плавный переход от красного (пусто) через оранжевый и жёлтый к лаймовому (полно). Шкала красит каждое своё деление по месту на шкале, число и значок — по уровню устройства. Это правило одинаково в окне, значке трея и панели. Ошибка — коралловый, неизвестный уровень — серый.

Главный вид — журнал: строки устройств, отсортированные по срочности (меньше заряда выше). В строке слева направо: значок типа, имя и состояние, шкала-линейка, число, действия. Устройства без данных о заряде не получают крупных пустых карточек: они собраны ниже в тихий раздел «Заряд не передаётся». Отключённые сохранённые устройства показываются только в фильтре «Все сохранённые».

Выбор сделан владельцем 2026-10-08 из четырёх вариантов окна, четырёх вариантов значка и четырёх вариантов реакции на значок (см. `docs/PRODUCT.md`).

## Токены

Единственный источник значений для окна — `src/EgoistBattery/App.xaml`. Значок и панель трея рисуются GDI+ без WPF и берут цвета заряда из того же `BatterySpectrum`; остальные цвета панели повторены в `TrayFlyout.Palette`. Меняя фон или текст, правьте `App.xaml` и `TrayFlyout.Palette`.

| Роль | Значение | Назначение |
|---|---|---|
| Background | `#0E1113` | фон окна, цвет заголовка Windows 11 |
| Surface / Raised / RaisedHover | `#14181B` / `#1B2125` / `#242B30` | наведение на строку, кнопки, поле поиска |
| Line / LineStrong | `#20272B` / `#313A40` | разделитель строк, рамка выбранного сегмента |
| Text / Muted / Faint | `#EDEFEE` / `#8E9A9F` / `#7A878C` | основной, вторичный текст, метки (контраст с фоном не ниже 4,5:1) |
| Track | `#283035` | пустые деления шкалы, дорожка переключателя |
| Спектр заряда (`BatterySpectrum`, Core) | `#FF5A4F` 0% → `#FFA53D` 25% → `#F6D84A` 50% → `#C6F24E` 100% | шкала, число, значок, панель; единственный источник |
| Tone.Error / Unknown | `#FF8F86` / `#7A878C` | ошибка, нет данных |

Радиусы: 6, 10 и капсула. Отступы кратны 2, основной шаг 4. В режиме высокой контрастности `App.ApplyAccessibilityColors` заменяет все роли системной палитрой; состояние тогда передают форма и текст.

## Типографика

- Заголовки разделов — Unbounded (SIL OFL, `Assets/Fonts/Unbounded.ttf`, лицензия рядом), встроен в программу.
- Текст — системный Segoe UI Variable Text.
- Числа заряда, метки разделов, служебные строки — Bahnschrift с табличными цифрами, поэтому «8%» и «100%» не сдвигают соседние элементы.
- Значки типов устройств — Segoe Fluent Icons с запасным Segoe MDL2 Assets.

## Компоненты и состояния

| Компонент | Состояния |
|---|---|
| Строка устройства | обычная, наведение, раскрытая (подробности: как получено показание), заряжается, низкий, критический, ошибка, без данных, отключено, значок трея скрыт |
| Шкала (`LevelRuler`) | 30 делений для процента; штриховка — остаток интервала (DualSense сообщает ступень 10%); четыре ступени для категорий Logitech («критический … высокий») |
| Число (`CountText`) | набегает от нуля при появлении и от прежнего значения при изменении; для интервала и категории показывает готовую подпись |
| Вкладки и фильтры | обычная, наведение, выбрана, фокус клавиатуры |
| Кнопки | основная (инверсия), вторичная, без рамки, иконка; наведение, нажатие, фокус, недоступна |
| Переключатель, ползунок | выключено, включено, наведение, фокус, недоступно (порог предупреждения без уведомлений) |
| Первое чтение | пульсирующие контуры строк вместо пустого окна |
| Пустое состояние | нет устройств, ничего не найдено (с кнопкой сброса фильтров), нет данных батареи |
| Сообщение | янтарная полоса с причиной, сохраняется до следующего успешного чтения |

## Движение

| Паттерн | Где | Параметры |
|---|---|---|
| Появление | страницы, строки списка, пустое состояние, подробности | прозрачность 280 мс и сдвиг 10 px за 520 мс, замедление «expo»; строки со ступенью 50 мс, не больше девяти |
| Заполнение шкалы | при появлении и при изменении уровня | деления заполняются по одному, 240–1100 мс по длине пути |
| Набегание числа | то же | 260–900 мс |
| Нажатие | кнопки | сжатие до 97% за 60 мс, возврат пружиной 300 мс |
| Переключатель | настройки | бегунок скользит 280–340 мс с лёгкой пружиной |
| Обновление | кнопка и верхняя линия | значок вращается, по верхней линии бежит лайм-отблеск, пока идёт чтение |
| Панель трея | наведение | появление около 75 мс (прозрачность), без сдвига |

Движение выключается, если отключены эффекты анимации Windows или включена высокая контрастность (`Motion.Enabled`): тогда экран сразу в итоговом виде. Отклик на действие (нажатие, наведение) всегда короче 120 мс. Самопроверка снимает кадры движения (`motion-*.png`).

## Значок в трее

Один значок. Яркая капсула почти во весь квадрат, цвет по заряду, крупное чёрное число (Segoe UI Black). Белая обводка (на светлой панели задач тёмная) — идёт зарядка. `10+` — интервал 10–19%. `?` — серая капсула, процент недоступен. Значок рисуется векторно отдельно для 16, 20, 24, 32, 40, 48, 64, 128 и 256 пикселей; число сжимается по ширине не больше чем до 72% нормы, поэтому «100» остаётся читаемым.

Устройство значка: закреплённое владельцем (булавка в строке окна); иначе DualSense или DualShock; иначе устройство с наименьшим зарядом (`TrayPolicy.IconDevice`).

## Панель трея

Показывается при наведении на значок (через 220 мс) и скрывается через 450 мс после ухода курсора со значка и панели. Содержит подключённые устройства с зарядом: устройство значка первым и подсвечено, остальные по срочности. Устройства без данных о заряде не показываются. Рисуется GDI+ в обычной форме WinForms без WPF и GPU: форма создаётся при наведении и уничтожается при уходе, фоновый процесс остаётся лёгким. Положение вычисляется по ближайшему к значку краю монитора (панель задач может быть с любой стороны или скрываться), масштаб берётся у монитора под курсором. Пока панель открыта, системная подсказка значка отключена. Если панель не удалось создать, остаётся прежняя системная подсказка.

## Компоновка

Колонка содержимого не шире 1000 DIP, шапка выровнена по ней. Окно от 720×480 DIP. Названия устройств переносятся, не обрезаются. Список прокручивается, шапка и фильтры остаются на месте. Все размеры в DIP, `UseLayoutRounding` и `SnapsToDevicePixels` включены; деления шкалы выравниваются по физическим пикселям.

## Доступность

Полное управление с клавиатуры, видимое кольцо фокуса (2 px, самый контрастный элемент экрана), имена элементов для программ чтения с экрана (`AutomationProperties.Name`), строка устройства озвучивается целиком: имя, заряд, состояние. Цели нажатия не меньше 24×24 DIP (WCAG 2.2 AA), кнопки-иконки 34×34. Цвет никогда не единственный носитель смысла: рядом всегда есть число, подпись категории или значок молнии.
