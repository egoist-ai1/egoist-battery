# Дизайн

## Визуальный язык

Интерфейс использует нейтральную тёмную палитру: фон `#101619`, поверхность карточек `#192125`, акцент `#B7F5CC`. Основной шрифт — Segoe UI Variable Text с запасным Segoe UI.

Числа заряда выделяются мягким свечением с низкой альфой. Их ядро остаётся непрозрачно-белым; рядом располагается тонкая полоска состояния. Значки на светлой панели задач используют тёмный текст.

В трее интервал DualSense обозначается числом со знаком `+`: `10+` означает 10–19%. Неизвестное значение показывается как `?`. Нейтральный управляющий значок имеет контур батареи.

## Компоновка и масштабирование

WPF-интерфейс учитывает DPI, включает pixel snapping и layout rounding. Карточки перестраиваются адаптивно в одну, две или три колонки. Названия устройств не обрезаются. Настройки размещаются в прокручиваемой области. При высоте окна менее 680 DIP сводные счётчики скрываются, освобождая место карточкам.

Динамические значки трея строятся из контуров `GraphicsPath` и растрируются GDI+ отдельно в размерах 16, 20, 24, 32, 40, 48, 64, 128 и 256 пикселей. Отрисовка значков использует GDI+ без GPU; выбранный системный размер учитывает DPI панели задач. WPF-окно и его типографика создаются по запросу при открытии окна; WPF настроен на программный режим отрисовки.
