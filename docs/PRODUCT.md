# Продукт

## Цель и пользователь

Локальный монитор заряда периферии для Windows: мышь, клавиатура, наушники, геймпад, батарея компьютера. Пользователь работает за компьютером и хочет одним взглядом видеть, что скоро сядет, не открывая окно производителя. Данные никуда не уходят, регистрации нет. Основная поверхность — значки и панель в трее; окно открывается редко.

## Главный сценарий

1. Значок рядом с часами показывает число заряда устройства; цвет значка говорит о состоянии.
2. Наведение на значок открывает панель со всеми подключёнными устройствами по срочности.
3. Двойной щелчок открывает окно: подробности, поиск, настройки, как получено показание.

## Решения владельца

Принято 2026-10-08 по визуальным вариантам (макеты в отчёте `reports/2026-10-08 Редизайн интерфейса/`).

| Вопрос | Выбор | Не выбрано |
|---|---|---|
| Структура окна | A · Журнал: строки по срочности, шкала-линейка, без данных — тихо внизу | Фокус (список + кольцо), Плитки, Виджет 360 px |
| Значок в трее | C · Капсула: число в заливке по уровню | Оставить как было, Цвет состояния (рекомендация), Кольцо |
| Реакция на значок | Панель по наведению | Панель по левому клику (рекомендация), только улучшить подсказку, панель вместо окна |

Уточнения владельца после первого просмотра (2026-10-08): один значок в трее с приоритетом DualSense вместо значка на каждое устройство; значок ярче и крупнее, число читается сразу; шкала цветная (лайм → жёлтый → красный) по заряду; устройства без данных (старый Impact 80, донгл) не должны мешать в панели, новые должны появляться сами; можно скрыть лишние.

Решено без вопроса (обратимо): шрифты без загрузок (Unbounded из соседнего проекта владельца, остальное системное), тёмная тема единственная, глагол «Обновить» остаётся основной кнопкой, шкала категорий Logitech рисуется четырьмя ступенями, а не процентом.

## Ограничения

- Только чтение устройств: правила проекта в `AGENTS.md` не меняются.
- Фоновый процесс не загружает WPF и GPU: значок и панель трея рисует GDI+.
- Данные, телеметрия, учётные записи не добавляются.

## Критерии приёмки интерфейса

| Критерий | Проверка | Статус |
|---|---|---|
| Устройства без данных не перебивают устройства с данными | снимки до/после, `reports/2026-10-08 Редизайн интерфейса/` | выполнено |
| Раскрытые подробности не сбрасываются при обновлении | `--ui-test`: раскрытая строка переживает `RefreshAsync` (тот же объект); прокрутка вручную не проверялась | выполнено |
| Окно целиком при 100/125/150/200% на Full HD, без обрезанного текста | `--ui-test`: снимки и проверка границ | выполнено |
| Все состояния: зарядка, низкий, критический, ошибка, интервал, категория, кэш Windows, без данных, отключено | `--ui-test --fixture`, снимки | выполнено |
| Движение выключается при отключённых эффектах Windows и высокой контрастности | код `Motion.Enabled`; вручную не проверялось | не проверено |
| Панель трея появляется при наведении и скрывается при уходе курсора | `--tray-hover-test` на настоящих значках | выполнено |
| Панель трея корректна при масштабах 100/150/200% | снимки `tray-flyout-*.png` | выполнено |
| Фоновый процесс не загружает WPF | код: панель на WinForms/GDI+; замер памяти фона после редизайна не проводился | не проверено |

## Следующие приоритеты

1. Светлая тема окна (сейчас только тёмная, панель задач Windows — обе).
2. Проверка панели трея на нескольких мониторах с разным масштабом вручную.
3. Замер фонового процесса после длительной работы с открывающейся панелью.
4. Журнал заряда по времени (нужно хранить историю; решение владельца).
